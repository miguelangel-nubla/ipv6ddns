# Home Assistant add-on: ipv6ddns

Keeps the DNS records of the devices of your network, found by their MAC
address, wherever their IPv6 and IPv4 addresses move: a Dynamic DNS client for
the whole network, with nothing to install on the devices.

[The documentation of the add-on](DOCS.md), and of
[ipv6ddns](https://github.com/miguelangel-nubla/ipv6ddns).
